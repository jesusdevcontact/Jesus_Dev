Sobre mí

Perfil enfocado en construir una base sólida, demostrable y útil para incorporarme a un entorno profesional.

Soy Jesús Martínez Escobar y estoy construyendo mi portfolio como desarrollador web dentro de una etapa de formación orientada a DAW. Me interesa especialmente el desarrollo full-stack, la claridad estructural del código y la mejora continua a través de proyectos reales.

Utilizo este portfolio para demostrar cómo abordo interfaces, organización frontend, lógica backend, persistencia de datos y documentación de proyectos con un enfoque profesional y progresivamente más completo.

Mi objetivo es incorporarme a una oportunidad profesional o de prácticas donde seguir aprendiendo, aportar compromiso técnico y convertir esta base en experiencia de producción real.

Enfoque de trabajo

Priorizo estructura clara, maquetación responsive, separación de responsabilidades y una base técnica que pueda mantenerse y ampliarse sin fricción.

Tipo de desarrollo

Trabajo webs corporativas, interfaces de gestión, prototipos funcionales y proyectos académicos o personales orientados a portfolio.

Objetivo profesional

Busco crecer dentro de un equipo donde pueda consolidar experiencia en frontend, backend y desarrollo web completo con impacto real.

StackPHP, Laravel, Filament, Tailwind CSS, MySQL, Git/GitHub
